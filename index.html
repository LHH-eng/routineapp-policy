개인정보처리방침

RoutineApp은 개인정보를
소중히 다룹니다

시행일: 2026년 1월 1일 최종 수정: 2026년 8월 29일

RoutineApp(이하 "서비스")은 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 서비스가 수집하는 정보의 종류, 사용 방법, 보호 방법을 설명합니다.

수집하는 개인정보

서비스는 다음 정보를 수집합니다.

구분 수집 항목 수집 방법
계정 정보 이메일 주소, Google 계정 정보(Google 로그인 시) 회원가입, Google 소셜 로그인
사용 데이터 루틴 기록, 할일, 독서 기록, 감사일기, 문구노트, 통계 데이터 이용자가 앱 내에서 직접 입력
앱 설정 알림 설정, 테마, 잠금 설정(패턴 해시값) 앱 사용 과정에서 자동 생성

패턴 잠금 비밀번호는 SHA-256 해시로 변환된 후 저장되며, 원본 패턴은 서버에 저장되지 않습니다.

수집 목적

  • 회원 인증 및 서비스 제공
  • 루틴, 할일, 독서 기록 등 이용자 데이터의 저장 및 동기화
  • 맞춤형 통계 및 성취 현황 제공
  • 앱 오류 수정 및 서비스 개선
  • 이용자 문의 응대

수집된 정보는 위 목적 이외의 용도로 사용하지 않습니다.

보관 기간

항목 보관 기간
계정 정보 및 사용 데이터 회원 탈퇴 시까지
탈퇴 후 데이터 탈퇴 요청 즉시 삭제 (단, 법령에 따라 보존이 필요한 경우 해당 기간)

이용자는 앱 설정 → 계정 → 회원 탈퇴를 통해 언제든지 탈퇴하고 데이터를 삭제할 수 있습니다.

제3자 제공 및 위탁

서비스는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만, 서비스 운영을 위해 아래 업체에 업무를 위탁합니다.

수탁 업체 위탁 내용 보관 기간
Supabase Inc. 데이터베이스 호스팅, 인증 서비스 위탁 계약 종료 시까지
Google LLC 소셜 로그인(Google OAuth), 앱 배포(Google Play) Google 정책에 따름

각 수탁업체의 개인정보 보호 정책은 해당 업체 웹사이트에서 확인하실 수 있습니다.

이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 열람: 본인의 개인정보 열람 요청
  • 수정: 잘못된 정보의 정정 요청
  • 삭제: 개인정보 삭제 및 회원 탈퇴 요청
  • 처리 정지: 개인정보 처리 정지 요청

권리 행사는 앱 내 설정 메뉴 또는 아래 문의처를 통해 요청하실 수 있으며, 10일 이내에 처리됩니다.

보안

서비스는 이용자의 개인정보를 안전하게 보호하기 위해 다음 조치를 취합니다.

  • HTTPS를 통한 데이터 전송 암호화
  • Supabase Row Level Security(RLS)를 통한 데이터 접근 제어 — 본인 데이터만 조회 가능
  • 패턴 잠금 비밀번호 SHA-256 해시 저장
  • 세션 토큰 AES-256 암호화 후 기기 내 보안 저장소(SecureStore) 저장

보안 취약점을 발견하셨다면 아래 문의 이메일로 즉시 알려주세요. 신속하게 대응하겠습니다.

아동 보호

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만 아동의 정보가 수집된 것을 발견할 경우 즉시 삭제 조치합니다.
